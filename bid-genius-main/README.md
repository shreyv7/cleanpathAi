# CleanPath AI – Bid Genius Dashboard

This is the standalone **Bid Genius** visualization dashboard for real-time bid shading and Bayesian multi-armed bandit telemetry pacing.

## Features

- **Real-Time Savings Tracker:** Displays savings in USD saved from the bid-shading filter.
- **Win Rate & Discount Metrics:** Shows simulated ad-auction win rates and optimal pricing discounts.
- **Dynamic Bid Savings Chart:** Visualizes real-time market value valuations versus shaded bids using interactive Recharts.

## Tech Stack

- **Framework:** React with Vite & TypeScript
- **Styling:** Tailwind CSS & shadcn-ui
- **State & Queries:** TanStack React Query

## Quick Start

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the local Vite server:
   ```sh
   npm run dev
   ```
