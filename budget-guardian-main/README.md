# CleanPath AI – Budget Control Center (Budget Guardian)

This is the standalone **Budget Guardian** control center for managing ad spend caps, PID-based pacing, and budget allocations.

## Features

- **Pacing Control Center:** Allows toggling between fast (ASAP) pacing and smooth (PID-based) pacing mode.
- **Dynamic Pacing Gauge:** Shows real-time spend burn rates versus expected pacing targets.
- **Cap Adjustments:** Provides slider and input controls to modify daily campaign budget ceilings.

## Tech Stack

- **Framework:** React with Vite & TypeScript
- **Styling:** Tailwind CSS & shadcn-ui
- **State & Queries:** TanStack React Query

## Quick Start

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the local Vite server:
   ```sh
   npm run dev
   ```
